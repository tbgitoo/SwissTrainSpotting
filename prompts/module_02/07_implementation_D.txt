PHASE D GOALS
==================================================

Add focused instrumentation tests that validate the following:

1) Preview image is displayed after loading
- Verify the ImageView in ImageClassificationActivity contains a drawable after a successful image load

2) EXIF correction is validated in an automated way
- Use controlled EXIF test images
- For EXIF cases where rotation should change aspect (for example 90°/270° cases), assert that the final displayed drawable/bitmap dimensions reflect the corrected orientation
- Do NOT rely only on visual judgment in automated tests

3) Activity recreation restores the image
- Recreate the activity during the test
- Verify that the previously displayed image is restored after recreation

4) Keep external UI out of the core automation path
- Do NOT try to fully automate the real external photo picker UI
- Prefer one of these approaches:
  - stub the outgoing intent/result with Espresso-Intents, OR
  - launch ImageClassificationActivity in a controlled way with a known test Uri if the app structure allows it cleanly
- Keep one final manual sanity pass for full picker/camera integration outside this implementation prompt
