## Exact tests to add

### 1. `resize_stretchesNon224UniformImage`

Implement a test matching plan §7:

- Create a **100 x 50** synthetic ARGB_8888 bitmap
- Fill every pixel with uniform `RGB(128,128,128)`
- Run `ImagePreprocessor.preprocess(...)`
- Assert:
  - returned length is `150528`
  - all values in the R, G, and B planes equal the normalized value for `128/255f`
- Use epsilon:
  - `1e-4f`

Purpose:
- proves resize to `224 x 224` occurred
- proves full output tensor is populated consistently after stretch resize
- avoids interpolation ambiguity because the source is uniform

### 2. `quadrantSpatialSanity`

Implement a test matching plan §7:

- Create a **224 x 224** synthetic ARGB_8888 bitmap
- Fill:
  - top-left quadrant = red `RGB(255,0,0)`
  - all other quadrants = black `RGB(0,0,0)`
- Run `ImagePreprocessor.preprocess(...)`
- Assert at minimum:
  - R-plane value at a top-left location such as `(x=50, y=50)` matches red-normalized expectation
  - R-plane value at a bottom-right location such as `(x=200, y=200)` matches black-normalized expectation
  - these differ beyond epsilon
- Also optionally assert G/B values at those locations if already consistent with local test style

Purpose:
- confirms spatial structure is preserved through sampling
- confirms layout/indexing is not accidentally interleaved or spatially scrambled

## Important correctness reminders

These are the main ways to drift incorrectly in Prompt 3:

- Do not confuse **packed bitmap pixels** with **planar tensor output**
- Do not write assertions as if output were interleaved `[R,G,B,R,G,B,...]`
- Use planar NCHW indexing:
  - `c * (width * height) + y * width + x`
- For the uniform resize test, remember:
  - the input pixel buffer is packed ARGB
  - the output tensor is planar float RGB
- For the quadrant test, assert against the **R plane**, not against packed color ints

Use the `packed-vs-planar` skill if any indexing or buffer-size uncertainty appears.
