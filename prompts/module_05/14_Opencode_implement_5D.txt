Task:
Implement Phase 5D only.

Goal:
Add presentation-aware routing logic so that:
- the generic MobileNetV2 classifier always runs first,
- the specialized classifier also always runs,
- the generic result determines whether the specialized result is presented as:
  1. direct specialized classification, or
  2. conditional / hypothetical specialized interpretation.

Critical Phase 5D rule:
- Do NOT gate specialized execution based on the generic result.
- The specialized classifier must still run and produce a result even when the generic result is out of scope.

Required behavior:
1. Run the generic MobileNetV2 classifier.
2. Run the specialized classifier on the same preprocessed tensor.
3. Check whether the generic top prediction belongs to the specialized profile’s allowed / compatible set.
4. If the generic result is in-scope:
   - present the specialized result directly (label + confidence).
5. If the generic result is out-of-scope:
   - still retain the specialized result,
   - present it conditionally / hypothetically,
   - also surface the generic result to the user,
   - keep wording concise but make the distinction between direct vs conditional specialized interpretation explicit.

Examples of intended meaning:
- In-scope: direct specialized result is shown.
- Out-of-scope: “Doesn’t look like a train; if it were a train, the closest class would be: Re420.”
The exact UI copy may be concise, but the distinction must be preserved.
