You are helping design a small but real project called SwissTrainSpotting.

Repository structure:
- SwissTrainSpottingApp/   -> Android Studio project (Java + XML, not Kotlin, not Compose)

- plans/                   -> planning documents

Project goal:
Build a lightweight Android app that allows the user to take a picture or select one from the device, then classify Swiss trains / locomotives / rolling stock locally on-device using an ONNX model. As a secondary feature, the app should attempt OCR-based extraction of visible train or locomotive numbers. The app should remain simple: no authentication, no backend, no cloud inference, no persistent storage. It should follow Android privacy best practices with minimal permissions and use the system photo picker where appropriate.

Current intended modules:
1. Android App UI
2. Image Acquisition & Permissions
3. Image Preprocessing Pipeline
4. Model Training & ONNX Export
5. ONNX Inference Integration
6. OCR / Train Number Recognition
7. Testing & Validation

Constraints:
- Android side must be Java + XML
- The project should be feasible in a short timeframe
- Dataset is very small (own photos, tens of images at most)
- Transfer learning is acceptable; the goal is a working end-to-end pipeline, not high classification accuracy
- Architecture should support sequential implementation with verifiable milestones
- Avoid overengineering
