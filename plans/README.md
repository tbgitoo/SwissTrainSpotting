# Plans

In this folder (plans, at the repo root) you can find 01_architecture.md which is the general architecture plan of this app. The app has been developped as set of modules, from module_01 to module_07.

You can find:

Plans for Modules 01-03 in the Android application: `SwissTrainSpotting/plans` in the form of `impementation_plan.md` files in their respective module folder.

The plan for Module 04 in the Python Machine Learning Pipeline: `model/plans/module_04/implementation_plan.md`

The plan for Module 07 is a general documentation and packaging module plan and its detailed implementation plan can be found at `plans/module_07/implementation_plan.md`
